# Repo Map

## Stack

- Framework: MkDocs
- Theme: MkDocs Material
- Public docs root: `ZJE_Collection/`
- Configuration: `mkdocs.yml`
- Styling: `ZJE_Collection/stylesheets/resource-center.css`

## Main routes

- Home: `ZJE_Collection/index.md`
- Year group navigation: `ZJE_Collection/Year1/index.md`, `Year2/index.md`, `Year3/index.md`, `Year4/index.md`
- Course routes: `ZJE_Collection/<course>/index.md`
- Contributor routes: `ZJE_Collection/<course>/<contributor>/index.md`
- Resource center: `ZJE_Collection/resources/index.md`
- Package index: `ZJE_Collection/ZIPS_INDEX.md`
- Folder bundle details: `ZJE_Collection/zip_contents/*.md`
- Contributors: `ZJE_Collection/AUTHORS.md`
- Contribution guide: `ZJE_Collection/CONTRIBUTING.md`

## Sources of truth

- Site navigation: `mkdocs.yml`
- Resource records: `ZJE_Collection/resources/resource_manifest.yml`
- Resource-page generation: `scripts/generate_resource_pages.py`
- Public route CSV: `ZJE_Collection/resources/download_links.csv`
- Maintainer reports: `resource_migration_reports/*.md`
- Release policy and migration model: `RESOURCE_MIGRATION_SPEC.md`

## Generated public files

Generated by `scripts/generate_resource_pages.py`:
- `ZJE_Collection/resources/index.md`
- `ZJE_Collection/ZIPS_INDEX.md`
- `ZJE_Collection/zip_contents/index.md`
- `ZJE_Collection/resources/download_links.csv`
- `Access:` headers in `ZJE_Collection/zip_contents/*.md`
- `resource_migration_reports/resource_status.md`

Prefer editing the manifest or generator over hand-editing these generated surfaces.

## Drift hotspots

- Course pages can drift from the resource center if they use stale wording.
- Folder bundle detail pages can drift if their `Access:` lines are edited by hand.
- `download_links.csv` can drift if not regenerated after manifest changes.
- `RESOURCE_MIGRATION_SPEC.md`, `README.md`, and `CONTRIBUTING.md` can describe outdated release logic if resource routing changes.
