    Resource Center¶

    ZJE study materials

    Download core PDFs from GitHub, browse everything else in OneDrive.

    GitHub hosts the PDF and Markdown files that are safe for normal repository storage. OneDrive hosts larger archives, Office files, OneNote, XMind, and any mixed-format course folders. Open a shared folder online to inspect contents, download one file, or download the whole folder.
